# **Portfolio Website**

This is a portfolio website built using React. It showcases my skills, projects, and experience.

## **Features**

* **Responsive Design:** The website is designed to be responsive and works well on different screen sizes.  
* **Project Showcase:** Highlights various projects with descriptions and links to GitHub.  
* **Skills Section:** Displays technical skills.  
* **Clean UI:** Provides a clean and user-friendly interface.  
* **Contact Section** Users can contact the me.

## **Technologies Used**

* React  
* HTML  
* CSS  
* JavaScript  
* MUI (Material UI)  
* Framer Motion  
* EmailJS

## **Project Description**

The portfolio website is a single-page application built with React, showcasing the skills, projects, and experience of Pavan Kumar, an aspiring data scientist. The website is designed to be responsive and visually appealing, with smooth animations and transitions.

* **Home Page:** The home page introduces Pavan Kumar, displays a profile picture, and provides links to the projects and contact sections.  
* **About Page:** The about page provides more information about Pavan Kumar's background, education, skills, and projects.  
* **Projects Page:** The projects page showcases Pavan Kumar's projects, including the Diamond Price Prediction Project, the Forest Fire Algerian ML Project, and the Flipkart Review Scraper.  
* **Contact Page:** The contact page allows visitors to send a message to Pavan Kumar using a contact form. Links to his GitHub and LinkedIn profiles are also provided.  
* **Navbar:** The website includes a navigation bar that allows users to easily navigate between the different sections of the website.

## **How to Run Locally**

1. **Clone the repository:**  
   git clone \<your\_repository\_url\>  
   cd \<your\_repository\_name\>

2. **Install dependencies:**  
   npm install

3. **Run the application:**  
   npm start

   The website will be accessible at http://localhost:3000.

## **GitHub Pages Deployment**

1. **Build the application:**  
   npm run build

2. **Deploy to GitHub Pages:**  
   npm run deploy

## **Customization**

* **Content:** Modify the content in the src/ directory to update the information on the website (e.g., projects, skills, experience).  
* **Styling:** Customize the styling by editing the CSS files or using a styling library (MUI).  
* **Components:** Add or modify React components in the src/components/ directory to change the structure and functionality of the website.  
* **Image:** The profile image is located at src/IMG-20240823-WA0039(4).jpg. Replace this file to change the profile picture.  
* **EmailJS:** The contact form uses EmailJS. You will need to replace the placeholder values for the service ID, template ID, and public key with your own EmailJS credentials in src/components/Contact.js.
